Cheat sheet

Every button, knob and key — one page. The short version also lives on the device: HOME on the MAIN page.

Always on

These work the same on every page.

PLAY
Start / stop. PLAY lights while playing. In EXT clock mode it arms and waits for clock.
EDIT
Next page: MAIN → DRUM → STEP → GEN → SYNTH → SYS. HOME goes back to MAIN — and HOME on MAIN opens the on-device cheat sheet.
SELECT encoder
Melody generator: Random · Markov · Euclidean · Contour.
PRESETS encoder
Scale (12 to choose from).
SEQ / REC
Next seed / random seed. Same seed, same tune.
OCT − / +
SHIFT the octave window up or down.
GLO
BLE MIDI on / off.
SAVE
Save settings now. They also autosave ~2 seconds after your last change, and load again on boot.
MASTER knob
Volume. Every key and button glows dimly; selected things light up fully.
FX / LFO
Reserved — effects and modulation are coming; the buttons do nothing yet.

MAIN — perform

The piano-roll home page.

K1 · K2 · K3 · K4
Density · DrumMap X · DrumMap Y · Tempo (40–240).
ALGORITHM enc
Swing — odd 16ths late; the melody swings too, one shared grid.
Keys
Play notes out over the sequence. Stopped, the bottom octave also sets the root.

DRUM — the Grids map

ENV cycles three knob banks.

MAP bank
K1 Fill A · K2 Fill B · K3 Chaos · K4 Pattern set (Grids 2 / classic).
MIX bank
K1 Kick level · K2 Snare level · K3 Hat level · K4 Accent velocity. Level 0 mutes the part, MIDI included.
SOUND bank
K1 Kick tune · K2 Kick decay · K3 Snare decay · K4 Hat decay (for the on-device voices).
SEL
Cycle channel A's part (kick / snare / hat). Channel B's part is set on the STEP page.
ALGORITHM enc
Swing.

STEP — XOX patterns

ARP opens this page from anywhere; ARP lights while you're on it.

White keys
The 16 white keys are the 16 steps. Press to cycle a step: off → on → accent → off. Key LEDs mirror the pattern; steps 1, 5, 9, 13 are marked on screen.
SEL
Flip the edited channel: kick ↔ snare.
ARP
On this page: cycle DrumMap channel B's part (kick / snare / hat / accent).
K1–K4
Kick level · Snare level · Hat level · Accent velocity.
ALGORITHM enc
Swing.
The rule
A channel with any step set replaces DrumMap for that part (the 16 steps loop twice per 32-step cycle). Clear all its steps and DrumMap takes over again. The hat always stays on DrumMap.

SYNTH — the voice

ENV cycles two knob banks. Every kick sidechain-ducks this voice.

FILTER bank
K1 Cutoff · K2 Resonance · K3 Filter-env amount · K4 Filter-env decay.
AMP ENV bank
K1 Attack · K2 Decay · K3 Sustain · K4 Release.
ALGORITHM enc
Waveform: sine · triangle · saw · square.

SYS — setup

Knobs are direction-aware: clockwise = EXT / ON, anticlockwise = INT / OFF.

K1
Clock: own tempo (INT) or follow MIDI clock in (EXT).
K2
Melody length: 4 / 8 / 16 beats (drums always loop 32 steps).
K3
Sync out: send clock + transport over USB.
K4
Notes in: MIDI notes pass through; stopped, a note also sets the root.

Drum mutes live on the keys, not a page: F♯3 · G♯3 · A♯3 — the first three black keys, top left — mute kick, snare and hat. They work during playback, the LED stays lit while muted, and the state is saved.
